# SYNC_WeatherFX（天気演出）仕様変更指示書

## 1. 変更概要

既存のSYNC_WeatherFXを、天候を個別に選択する方式から、複数の天候や天体をまとめて制御できる統合型の天気演出へ拡張する。

- プロジェクト名：SYNC_WeatherFX
- 日本語プラグイン名：天気演出
- グループ名：SYNC
- 開発言語：Delphi
- 対象：AviUtl2
- 形式：単体配置可能なフィルター

既存の太陽、月、雲、雨、雪、虹などの描画処理は可能な限り再利用する。ユーザーが時刻、曇り具合、雨量、雪量、風速などを変更するだけで、自然な天候の変化を表現できるようにする。

各種設定はグループ分けし、通常表示されるパラメーター数を削減する。新規作成ではなく、既存機能の拡張と再構成を基本とする。

## 2. 天気プリセット

設定項目の最上部に「天気プリセット」を設ける。

プリセットは、各パラメーターへ適切な初期値を一括設定するためのものとする。

### プリセット候補

- 晴れ（標準）
- 快晴
- 薄曇り
- 曇り
- 雨
- 豪雨
- 雪
- 吹雪
- 雷雨
- 朝焼け
- 夕焼け
- 夜
- 星空
- 霧

### 適用方法

1. ユーザーがプリセットを選択する。
2. 「設定を反映」を実行する。
3. 該当プリセットの初期値を各パラメーターへ設定する。
4. ユーザーが必要な項目を自由に調整する。

プリセットは初期値設定用であり、その後のパラメーター編集を制限しない。プリセットを選択しただけでは、編集中の値を変更しない。再適用しない限り、ユーザーの編集値を勝手に初期値へ戻さない。

新規配置時は「晴れ」を自動適用する。

## 3. 初期状態

新規配置時は、画像素材がなくても、プラグインを追加するだけで昼間の晴れた空を表示する。

| 項目 | 初期値・表示 |
| --- | --- |
| プリセット | 晴れ |
| 時刻 | 11.0 |
| 曇り具合 | 35 |
| 雨量・雪量 | 0 |
| 風速 | 10（雲がゆっくり流れる） |
| 風向 | 0度（右向き） |
| 風表現 | 0 |
| 太陽透明度 | 0（表示） |
| 月透明度 | 100（非表示） |
| 虹透明度 | 100（非表示） |
| 太陽 | 上寄りの白い発光体（X=160、Y=-200、直径64） |
| 雲 | 白い上面と青灰色の下面を持つ、多めの積雲。遠くほど小さくする |
| 空 | 参考画像にある、白い積雲との対比が明確な濃い青空 |

雲の色合いは維持し、雲ごとの輪郭・高さ・横幅に変化を付ける。時間経過で画面外へ流れた後も、風上側から異なる形の新しい雲を出現させ、雲が尽きないようにする。同じ時刻へのシークでは同じ雲を再現する。

## 4. パラメーターのグループ化

各グループを折りたたみ可能とし、通常は必要な項目だけを表示する。

| グループ | 項目 |
| --- | --- |
| 基本設定 | 時刻、曇り具合 |
| 雨・雪 | 雨量、雪量、雨粒サイズ、雪片サイズ、落下速度 |
| 風 | 風速、風向、風表現の強さ |
| 太陽 | X座標、Y座標、サイズ、透明度 |
| 月 | X座標、Y座標、サイズ、透明度、満ち欠け、欠ける方向 |
| 虹 | X座標、Y座標、半径、円弧角度、帯幅、透明度 |
| その他の天候 | 雷、霧、オーロラ、陽炎、蜃気楼、星、流れ星など |

既存機能を削除する必要はない。SDKの標準UIで折りたたみが実現できない場合は、専用設定画面などの代替方式を検討する。

## 5. 時刻パラメーター

- 最小値：0.0
- 最大値：240.0
- 初期値：12.0
- 小数で指定可能。

24.0で1日が終了し、次の日の0時に相当する。内部処理は24時間周期とし、240時間で10日間を表現する。

| 値 | 意味 |
| --- | --- |
| 0.0 | 1日目0時 |
| 6.5 | 1日目6時30分 |
| 12.0 | 1日目12時 |
| 18.0 | 1日目18時 |
| 24.0 | 2日目0時 |
| 36.0 | 2日目12時 |
| 240.0 | 11日目0時（10日間経過） |

時刻によって空の色、グラデーション、明るさ、朝焼け、夕焼け、夜空、雲の色と明るさを連続的に変化させる。

朝焼け・夕焼けの赤、オレンジ、黄色が広がる演出は6時と18時を中心に強める。画面のY最下端を地平線・水平線として、上空の青紫から下方の暖色へ滑らかにつなぎ、太陽付近の下空へ柔らかな光を加える。効果はそれぞれ4.75～7.25時、16.75～19.25時の範囲で連続的に増減する。厳密な波長別の散乱計算ではなく、映像演出として近似する。

太陽を水平線へ近づけた場合は、そのX/Yに追従して周囲の背景と雲を特に明るくする。内側の白黄の光から外側の橙色へ滑らかにぼかし、太陽光と背景色が溶け合う表現とする。太陽を上へ移動すると弱まり、透明度100ではこの局所光も表示しない。

朝焼けプリセットは時刻6、夕焼けは18とする。反映時のシーン解像度を使い、太陽の下端が画像下端の約98%の位置になるよう初期配置する。反映後は従来の太陽X/Yで編集できる。夜プリセットの曇り具合は30とする。

季節や緯度に基づく正確な天文計算は不要。動画演出として自然に見える変化を優先する。AviUtl2の中間点で連続的に変更でき、24時間の境界で不自然に飛ばないこと。

## 6. 曇り具合

- 範囲：0～100
- 初期値：20

0は快晴、100は非常に厚い雲に覆われた雨天直前のような空とする。雲量・雲密度・雲色・空の明るさと彩度・太陽光の弱まりへ反映する。

時刻と曇り具合は独立したパラメーターとし、描画時に相互作用させる。

| 条件 | 表現 |
| --- | --- |
| 昼・曇り0 | 鮮やかな青空 |
| 昼・曇り50 | 白い雲が増える |
| 昼・曇り100 | 暗い雨雲に覆われる |
| 夕方・曇り50 | 赤や橙色の雲 |
| 夕方・曇り100 | 暗い赤紫や灰色の雲 |
| 夜・曇り50 | 暗い空に雲が見える |
| 夜・曇り100 | 厚い暗雲に覆われた夜空 |

曇り具合100でも、雨量0なら雨は降らない。雨量・雪量の変更で曇り具合の数値を自動変更する必要はない。

## 7. 雨・雪

雨量と雪量は独立し、ともに範囲0～100、初期値0とする。0で降らず、100で最大の豪雨・降雪とする。中間値では発生数や密度を連続的に変える。

雨と雪は同時表示できてもよい。雨粒・雪片のサイズと落下速度を調整できるようにする。物体との当たり判定は不要。

## 8. 風

- 風速：0～100、初期値0。
- 風向：0～360度。
- 風表現の強さ：0～100、初期値0。

風は雲・雨・雪・霧などに影響する共通要素とする。風速に応じ、雲の移動速度、雨の落下方向、雪の横流れ、霧の移動などを変える。

風表現0では、流線などの風そのものを描画しない。風速があっても風表現0で雲・雨などへの影響だけを与えられるようにする。風表現を大きくすると、流線や空気の揺らぎを追加する。

## 9. 太陽

太陽の位置は時刻と独立して、X座標・Y座標・サイズ・透明度で指定する。

透明度は0～100、初期値0。0で完全表示、100で非表示とする。プリセットによって初期値を変えてよい。

本体は常に完全な円とし、地平線でのクリッピングはAviUtl2側の後段フィルターに任せる。時刻による自動移動は行わない。時刻に応じた色・発光・周囲の光の変化は許容する。

## 10. 月

太陽とは独立したX座標・Y座標・サイズ・透明度・満ち欠け・欠ける方向を用意する。

透明度の初期値は100。満ち欠けを数値で自由に変更し、満月・半月・三日月などを表現する。

太陽と月の同時表示を禁止しない。昼間の月や特殊な演出にも対応する。

## 11. 虹

独立したX座標・Y座標・円弧半径・円弧角度・帯幅・透明度を用意する。

透明度の初期値は100。非常に大きな半径を考慮し、円弧角度で表示範囲を変更できるようにする。二重虹などの既存機能を可能な限り維持する。

雨量や時刻によって、虹を強制的に表示・非表示にしない。

## 12. その他の現象

雷・霧・陽炎・蜃気楼・オーロラ・星・流れ星・日差し・月明かりを、必要なものだけ有効にできる構成とする。既存の描画処理は維持・再利用し、変更前に未実装だった現象は今回の追加対象として扱う。

表示量・強度は可能な範囲で0～100とし、0で無効、100で最大を基本とする。座標・角度・サイズには適切な範囲を使う。項目が過大になる場合はグループ化や専用設定画面で整理する。

雷には線の太さ（0～100px）と全面発光（0～100）を設ける。線の太さ0で全面発光のみ、全面発光0で雷線のみを表示できる。雷の量が0なら両方を無効にする。雷雨プリセットは雷80、線幅14、全面発光75とする。

星サイズ（0～100）と流れ星頻度（0～120回/分）を調整できるようにする。星空プリセットでは星サイズ4、流れ星75、頻度12回/分で有効にする。流れ星の出現時刻・軌道をランダムにし、同じタイムライン時刻とシードで再現する。頻度0は発生なし。

霧は白いもやを重ねる描画とする。霧プリセットは時刻12、曇り0、太陽非表示、霧85、風速5を初期値とする。空を描かない場合は元画像へ白いもやだけを合成する。

薄曇りプリセットは曇り55、太陽透明度25、風速10とし、晴れより白い雲の量を増やす。曇りプリセットは曇り68、太陽透明度55として暗くなり過ぎないようにする。雲の出現量の変化は小さな雲の成長で表し、大きな雲全体を不自然に半透明へ変えない。雪の雪片サイズは10、吹雪は14へ大きくする。

## 13. アニメーション

各パラメーターは可能な限りAviUtl2の中間点・移動設定に対応する。

- 時刻12→18：昼から夕方へ。
- 曇り具合0→100：快晴から曇天へ。
- 雨量0→100：徐々に強くなる雨。
- 風速0→80：徐々に強くなる風。
- 太陽透明度0→100：太陽が消える。
- 月透明度100→0：月が現れる。

描画はタイムライン時刻と現在の設定から決定し、同じ時刻・設定では同じ結果を返す。シーク、途中再生、逆方向移動、書き出しで不自然に変化しない。

## 14. レイヤーとの関係

統合型を基本とし、1つのプラグインで空・雲・雨・雪・風・太陽・月・虹などを組み合わせる。

従来の個別スタイルによる描画も可能な限り維持する。必要に応じて複数のSYNC_WeatherFXをレイヤーに置き、異なる演出を追加できるようにする。既存の個別スタイルを廃止する必要はない。

## 15. 描画品質・性能

現在の青空の品質を維持し、既存の描画処理を安易に作り直さない。時刻や曇り具合の変化は自然に補間し、急激に表示を切り替えない。

朝焼け・夕焼け、昼間の青空、夜への移行、雲色と時刻の関係、曇り具合と雲量、雨雪の密度、風の自然な移動、複数現象の同時表示を重視する。

表示量0や透明度100の演出は不要な描画処理を省略する。CPU負荷を抑える。

## 16. 実装方針

既存のSYNC_WeatherFXをベースに改修する。

優先順位：

1. 現在の青空描画を維持する。
2. 時刻と曇り具合による空の連続変化を実装する。
3. 雨・雪・風の共通制御を実装する。
4. 太陽・月・虹の独立パラメーターを追加する。
5. パラメーターをグループ化する。
6. 天気プリセットと設定反映機能を実装する。
7. その他の既存スタイルを統合する。
8. 描画性能を調整する。

SDKで実現できるUI機能を確認し、折りたたみや一括設定が難しい場合は代替方式を検討する。

追加直後に「晴れ」が表示され、天気プリセットと「設定を反映」で目的の天候を作れることを最優先とする。その後、個別パラメーターで複雑な天候変化や昼夜の移り変わりを表現できるようにする。

従来の個別方式の仕様は `archive/SPECIFICATION_INDIVIDUAL_2026-11-17.md` に保存する。現在の仕様は本書を優先する。実装と検証の状況は `IMPLEMENTATION.md` と `../note.md` に記録する。
